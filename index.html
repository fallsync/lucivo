Analyseur APK

Recherchez une application par son nom, ou choisissez un ou plusieurs fichiers APK. Ils sont lus uniquement sur votre téléphone. Seuls les résultats peuvent être envoyés à votre base, et seulement si vous le demandez.

Rechercher une application

Tapez le nom d'une application (ex. Exodus, WhatsApp, Termux) pour voir sa fiche de confidentialité en langage simple.

    Aide à interpréter les permissions. Le type n'est jamais deviné : en cas de doute, laissez « Non précisé » et l'interprétation reste neutre.

    Limites de cette analyse
    • L'analyse porte uniquement sur le fichier APK fourni. Rien ne prouve qu'il est identique à la version actuellement distribuée par un magasin d'applications.
    • La détection des SDK dépend de la liste de signatures LUCIVO v1 (64 SDK). Un SDK absent de la liste, ou un code obfusqué, peut ne pas être détecté.
    • La présence d'un SDK ne prouve pas qu'une donnée est effectivement collectée ou envoyée.
    • Une analyse statique ne permet pas de connaître les données réellement transmises, ni vers quels serveurs.
    • Lorsque le manifeste référence une Network Security Config, Lucivo signale qu'elle doit être examinée séparément ; l'attribut usesCleartextTraffic seul ne suffit pas à conclure sur la politique HTTP effective.
    • Une partie du code peut être téléchargée ou chargée après l'installation et n'apparaît donc pas ici.
    • Une permission déclarée n'indique pas qu'elle est utilisée, ni qu'elle a été accordée par l'utilisateur.
    • L'indice de confidentialité est un indicateur heuristique fondé sur des règles configurées manuellement. Il ne mesure pas les flux réseau réels et ne prouve ni la sécurité ni le danger d'une application.
    Avis important
    • Lucivo est un outil d'analyse indépendant, fourni à titre informatif. Il n'est affilié à aucun éditeur d'application ; les noms et marques cités appartiennent à leurs propriétaires.
    • Les résultats viennent d'une analyse automatique du fichier fourni. Ils peuvent contenir des erreurs ou des omissions et ne constituent ni une accusation, ni un avis juridique, ni une garantie.
    • Vous devez vous assurer d'avoir le droit d'analyser le fichier que vous choisissez.

    Explication par l'IA

    Facultatif. Seul un résumé du rapport (permissions, SDK, configuration, indice) est envoyé, jamais l'APK. Utilise l'adresse, la clé et le code secret de « Envoi direct vers ma base ». Le rapport technique reste disponible sans l'IA.

    La réponse repose uniquement sur ce rapport. Pas d'historique : chaque question est indépendante.

    Enregistrer dans Lucivo

    Configurez d’abord la fonction Edge « lucivo-import » avec le paquet fourni, puis copiez ce SQL dans le SQL Editor Supabase. Le SQL retire l’ancien RPC public direct ; sauvegardez votre schéma avant exécution.

    Envoi direct vers ma base

    L'APK reste sur votre téléphone. Seuls les résultats sont envoyés, et seulement si vous touchez « Envoyer à ma base ». Une configuration unique est nécessaire dans Supabase.

    Auto-test du moteur

    Vérifie la logique de l'indice et du classement sur des données fictives. Rien n'est envoyé ni enregistré.
